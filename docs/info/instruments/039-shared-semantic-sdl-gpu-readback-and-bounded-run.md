## Instrument

Shared semantic SDL GPU readback and bounded-runtime summary

## Validated by

The production client encoded an empty frame and measured exactly zero non-clear pixels, then
encoded planted picture, resource-font glyph, and solid-rectangle operations through the same
ordered path and measured non-clear pixels plus known-different order/content hashes. Duplicate
consumption was visibly refused. Coverage is limited to those operation families: it does not prove
windows, `J2DGrafContext::fillBox`, 3D, mip chains, particles, lights, effects, appearance
correctness, or title-level parity. The watcher control independently plants a kernel-fault line
and proves it kills the exact owned process group before a clean GPU result is trusted.
